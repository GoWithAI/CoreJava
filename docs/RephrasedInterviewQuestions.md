# Rephrased Interview Questions

This document contains rephrased, concise versions of common Java and database interview questions.

0. How does the Java ClassLoader work?
1. Compare ArrayList, LinkedList, TreeSet, HashMap, and ConcurrentHashMap.
2. Explain Try-with-resources and Java Streams (Intermediate vs Terminal operations, `flatMap`, `reduce` vs `collect`).
3. What happens if a class implements two interfaces with identical method signatures?
4. Explain ACID properties, SOLID principles, Pessimistic vs Optimistic locking, and Eager vs Lazy loading.
5. What are the different types of relationships between entities?
6. What is a Native Query?
7. Explain the `@Transactional` annotation and isolation levels in transactions.
8. What is the JPA/Hibernate Entity Life Cycle?
9. JUnit: Difference between `@Mock`, `@InjectMocks`, and `@Spy`. What is `@ParameterizedTest`? How to achieve 100% code coverage?
10. Differentiate between Static Binding and Dynamic Binding.
11. Explain "IS-A" vs "HAS-A" relationships.
12. What happens if one thread modifies a list while another thread is iterating over it?
13. Explain `AtomicInteger` and why `a++` is not thread-safe. How does it achieve non-blocking thread safety?
14. Difference between Join and Subquery. `WHERE` vs `HAVING` clause. How to optimize a slow query?
15. What is Database Indexing?
16. How to create an Immutable class? Why is `String` immutable in Java?
17. How to implement a Thread-safe Singleton class?
18. How does HashMap handle collisions, and how can they be avoided?
19. Why is only one `null` value allowed in a `Set`?
20. Compare `HashSet`, `LinkedHashSet`, and `TreeSet`.
21. How does `ArrayList` resize itself internally?
22. What is the time complexity of adding an element in the middle of an `ArrayList` vs a `LinkedList`?
23. In inheritance, if a child method throws `FileNotFoundException`, what exceptions can the parent method throw?
24. Difference between Method Overriding and Method Hiding (static methods).
25. How does Java manage memory (JVM Heap vs Stack)?
26. What is Cascading in JPA/Hibernate?
27. Provide an example of `CascadeType.REMOVE`.
28. Which AI tools (Copilot, Cursor, Claude) do you use for development?
29. Compare `ExecutorService`, `CompletableFuture`, and Virtual Threads.
30. Explain the internal working of `ConcurrentHashMap`.
31. What are the built-in Functional Interfaces in Java 8?
32. How to find all palindromes in a list of strings using Java 8 Streams?
33. How to find the word with the second largest length in a sentence using Java 8?
